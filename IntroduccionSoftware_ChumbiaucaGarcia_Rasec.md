# Ejercicio 1

### ¿Qué es es un programa informatico?

Un programa informatico es una serie de instrucciones claras que se le da al ordenador a realizar tareas 

### Diferencias entre código

- **Codigo Fuente**: Es el texto hecho por el programador
- **Codigo Objeto**: traducido para que la maquina lo entienda e interprete, suele estar en binario
- **Codigo Ejecutable**: Es el código fuente ya empaquetado para iniciarse en un exe 

## Etapas del desarrollo del Software

Son 7 etapas en total y son:
- **Planificacion**: Momento base ne donde se reconoce cual es el objetivo , a que publico se quiere alcanzar y todos los requerimentos que vaya a tener el programa 
- **Analisis**: Etapa de recopilacion de ideas sobre los requisitos 
- **Diseño**: Un diseño inicial ;*una idea visual base* del proyecto
- **Codficacion**: Se escrie el codigo fuente 
- **Pruebas**: Se compila para revisar errores y eliminarlos 
- **Implementacion**: Lanzamiento inicial disponible para los usuarios
- **Manenimiento**: Auditorias para evaluar mejoras y realizar correcciones
